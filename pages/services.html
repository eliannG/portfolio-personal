SERVICIOS

Diseño Web

A gusto del cliente, se le realiza un diseño de un sitio web.

En el mismo se tendrán en cuenta criterios previamente acordados con el cliente, como la colorimetría a aplicar, personalidad del sitio, textos, animaciones, etc.

Para llevar a cabo estos puntos, el cliente puede enviar un diseño pre-existente para modificarlo o generar un diseño completamente nuevo a través de una reunión virtual anteriormente pactada.

Desarrollo Web

A partir de un diseño, se desarrolla un sitio web estático mediante el uso de HTML5 y CSS3.

El plazo de entrega se acuerda previamente con el cliente. En el transcurso del desarrollo del sitio, se le irá informando periódicamente al cliente como evoluciona el trabajo.

Además de un constante contacto con el cliente, si durante el desarrollo del sitio ocurre una disconformidad relacionada con el diseño, este puede ser modificado en los aspectos que le hayan causado disconformidad.

Subida al hosting

Se publica su sitio web en internet.

Su sitio web terminado, a través de un único pago anual, obtiene un dominio propio, a elección del cliente.

También se otorga la posibilidad (incluida en el único pago anual) de poseer un mail con dominio propio, por ejemplo: contacto@nombredeempresa.com.

Mantenimiento Web

Periódicamente, se realizan tareas de sostenibilidad y mantenimiento de su sitio.

Cada cierto tiempo, su sitio recibe mantenimiento, el cual es necesario para garantizar que su sitio se muestre siempre correctamente a los visitantes.

Atención al cliente

La satisfacción del cliente es lo principal.

En cada etapa y servicio el contacto y la comunicación es fundamental para lograr un resultado de excelente calidad.

El cliente puede solicitar y programar reuniones para cuando lo vea necesario.

Extra - Imágenes Aéreas

Para complementar con su sitio, puede solicitar imágenes aéreas de su negocio.

La tecnología en general me apasiona y el mundo de los drones no es la excepción. Puedo ofrecer como extra la captura de imagenes de su negocio con un drone.
